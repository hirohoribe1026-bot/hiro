# 講師写真の置き場所

このフォルダに以下のファイル名で4枚の写真を入れると、LP（index.html）の「講師紹介」に自動で表示されます。

| ファイル名 | 使う写真 | 表示場所 |
|---|---|---|
| `hiro-01.jpg` | 登壇写真（SPIRITUAL ACADEMY・青ジャケット） | メイン（大きく表示） |
| `hiro-02.jpg` | 南仏・石門前（ティールのジャケット／白パンツ） | ギャラリー左 |
| `hiro-03.jpg` | タキシード（黒・蝶ネクタイ） | ギャラリー中央 |
| `hiro-04.jpg` | ピンクジャケット（白背景・笑顔） | ギャラリー右 |

※ ファイル名は上記のとおりにしてください（拡張子が `.png` の場合は index.html 側の `src` も合わせて変更が必要です）。
