# ミラコレ向け スピリチュアルビジネスセミナー 第1弾 1回目資料

ミラクルコレクション メンバー限定で開催する、スピリチュアルビジネスセミナーの第1弾1回目（2026年5月）の運営資料一式です。

---

## ゴール

- **短期（5〜8月）**：参加者が有料で個人セッションを1件獲得する体験をする
- **長期（9月）**：信頼関係ができた参加者に「THE REAL（スピリチュアルビジネスアカデミー）」を案内する

第1弾1回目は、**「現在地を知るためのQ&Aライブ」**として開催します。

## 1回目で守ること

1. **THE REALの匂わせはしない** — 売り込み臭が出ると次回以降の参加率が落ちる
2. **講義モードに入りすぎない** — 対話の時間を多く取る
3. **時間を絶対に押さない** — 1:25には終わりに入る
4. **情報量を詰め込まない** — 「また聞きたい」と思わせれば成功

---

## 終了後にやること

- 録画をミラコレ限定で1週間配信
- お礼メッセージをLINEで配信（当日中）
- 次回の日程を72時間以内に告知
- 多かった質問をメモして次回コンテンツに反映
