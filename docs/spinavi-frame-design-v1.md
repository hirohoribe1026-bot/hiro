# スピなび 全体設計・フレーム（1か月公開版 v1）

作成日：2026-08-18
位置づけ：本ドキュメントが **1か月後公開の正式スコープ** です。[miracle-collection-booking-strategy.md](./miracle-collection-booking-strategy.md) と [spinavi-migration-and-design.md](./spinavi-migration-and-design.md) に書いた診断機能・詳細ランキング・月額継続・自動マッチング等は**第2フェーズ（公開90日後以降）の構想**として保持し、今回のスコープからは外します。

## 0. スコープの確定

**公開の完成基準（これだけ）**

> 利用者が3分以内に自分に合うセッションを見つけ、スマートフォンで予約・決済まで完了できること

**通す導線は3つだけ**

```
① 悩みから探せる → ② 安心して比較できる → ③ その場で予約・決済できる
```

診断アプリ、AIマッチング、細かいランキングスコア、月額コース、ポイント制度、専用YouTube、外部専門家の一般募集は今回作らない（詳細は11章）。

---

## 1. スピなびの役割

単なる予約サイトではなく、

> 「悩みを持つ人と、信頼できる専門家をつなぐ、ダイナビジョン公式の個人セッション検索・予約サイト」

- **利用者にとって**：自分の悩みに合う、安心できる専門家を見つけられる場所
- **ミラクルコレクション会員にとって**：自分だけでは出会えなかった相談者とつながり、活動実績を作れる場所

---

## 2. 全体導線（フレーム）

### 利用者側

```
トップページ
  └─ 悩みから選ぶ／セッションから選ぶ
        └─ 検索結果一覧（比較できる形式）
              └─ 専門家 個人ページ
                    └─ 予約カレンダーで日時選択
                          └─ 事前相談フォーム
                                └─ カード決済
                                      └─ 予約確定通知（メール／必要ならLINE）
                                            └─ 前日・当日リマインド
                                                  └─ セッション実施
                                                        └─ 翌日：感想依頼
                                                              └─ 7日後：再予約案内
```

### 掲載側（ミラコレ会員）

```
ミラコレ会員へ掲載案内
  └─ 掲載希望フォーム入力
        └─ 掲載条件の確認
              └─ プロフィール・写真・商品情報を提出
                    └─ 事務局が内容確認
                          └─ 本人が最終確認
                                └─ スピなび公開
                                      └─ 予約枠更新・予約対応・セッション実施・口コミ依頼
```

この2本の導線が問題なく回ることが、1か月公開版の完成条件。

## 3. サイト構成（サイトマップ）

各ページの**最低限の構成要素**を確定する。ここに書かれていないもの（診断結果ページ、ランキングページ、月額プラン申込ページ等）は今回作らない。

### 3.1 トップページ

表示順は「誰がいるか」より「どんな悩みを相談できるか」を先に見せる。

1. メインメッセージ：「今の悩みに合った、信頼できる専門家が見つかる」＋「ダイナビジョン認定メソッドを学んだ専門家の個人セッションを、検索・比較・予約できます」
2. 悩みから探す（6カテゴリー固定）
3. セッションから探す（6カテゴリー固定）
4. 今月のおすすめ（編集部おすすめ6名。ランキングではない）
5. 初めての方へ（リンク）
6. 専門家になる・掲載する（ミラコレ入会案内へのリンク）

**悩みカテゴリー（6つ・固定）**

- 恋愛・夫婦・パートナーシップ
- 仕事・起業・お金
- 才能・使命・人生の方向性
- 家族・人間関係
- 自信・自己価値・心の癒し
- 魂・ハイヤーセルフ・スピリチュアル

**セッションカテゴリー（6つ・固定）**

- スピリチュアルカウンセリング
- ヒーリング
- チャネリング・リーディング
- 瞑想・エネルギーワーク
- パートナーシップ相談
- 才能・使命・起業相談

### 3.2 検索結果一覧ページ

**絞り込み条件（これだけ）**：悩み／セッション内容／価格帯／オンライン・対面／予約可能日／活動地域／ダイナビジョン認定の有無

**一覧カード1件ごとの表示項目**：顔写真／専門家名／専門分野が一言でわかる説明／対応できる悩み3つ／セッション名・時間・価格／オンライン・対面／直近の予約可能日時／ダイナビジョン認定表示／詳細ボタン／予約ボタン

→ 名前と写真だけの一覧にはしない。「この人が何をしてくれるか」が3秒でわかることが必須条件。

### 3.3 専門家 個人ページ（全員同一フォーマット）

1. 誰の、どんな悩みに対応する専門家か
2. セッションで期待できる変化
3. 提供するセッション（最大3商品）
4. 得意な相談内容
5. セッションの流れ
6. プロフィール／習得メソッド・認定資格
7. 担当者本人のお客様の声
8. 料金・時間・キャンセル条件
9. 予約可能日時
10. 予約・決済ボタン

自己紹介動画は公開後の追加でよい。文章量より「誰に何を提供する人か」を明確にする。

### 3.4 予約・決済フロー

日時選択 → 事前相談フォーム（名前／メール／電話／相談したい内容／得たいこと／過去の利用経験／注意事項同意／個人情報同意）→ カード決済 → 完了通知

### 3.5 その他必須ページ

- 初めての方へ（相談内容・医療行為ではないこと・流れ・キャンセル方法・強引な勧誘をしないこと）
- 専門家になる・掲載する（ミラコレ導線）
- 法務ページ群：利用規約／プライバシーポリシー／特定商取引法に基づく表記／キャンセル・返金規定／免責事項（医療・診断・治療ではないことの明示）／責任範囲／問い合わせ窓口／口コミ掲載規定

### 3.6 管理画面（ライト版でよい）

**専門家用**：プロフィール確認・修正依頼（事務局承認制）／商品登録（最大3）／予約枠の登録・変更／予約者情報確認／予約履歴／売上確認／事務局への問い合わせ

**事務局用**：専門家の登録・公開・停止／商品の承認／予約確認／決済・返金確認／専門家別売上／顧客情報／問い合わせ管理／口コミの公開承認／月間予約件数の集計

「誰に何件予約が入り、いくら売れたか」が事務局側で常に見えることが最重要。

## 4. 最低限のデータモデル

新規開発でも、既存SaaSの組み合わせでも、以下の実体（エンティティ）とその紐づけがあれば1か月公開版は成立する。

| エンティティ | 主な項目 | 紐づけ |
| --- | --- | --- |
| 悩みカテゴリー | 名称（6固定） | 商品／専門家に複数付与 |
| セッションカテゴリー | 名称（6固定） | 商品に付与 |
| 専門家 | プロフィール、認定資格、顔写真、活動地域、認定表示フラグ、公開/停止状態 | 商品を最大3つ、悩みカテゴリーを複数 |
| 商品（セッション） | 名称、時間、価格、形式（オンライン/対面）、悩み・セッションカテゴリー | 専門家1名、予約枠 |
| 予約枠 | 日時、空き状況 | 商品・専門家に紐づく |
| 予約 | 顧客、商品、専門家、日時、金額、状態（仮／確定／完了／キャンセル） | 決済・通知に連動 |
| 決済 | 予約ID、金額、状態、手数料 | 専門家別売上集計の元データ |
| 口コミ | 予約ID、専門家ID、コメント、公開承認状態 | 専門家個人ページに表示 |
| 顧客 | 名前、連絡先、予約履歴 | 予約に紐づく |

悩みカテゴリーとセッションカテゴリーを「専門家」と「商品」の両方に付与しておくことで、「悩みから探す」「セッションから探す」のどちらの入口でも同じ検索結果に辿り着ける（診断機能なしでも実現可能）。

## 5. 商品設計（1人最大3商品）

| 商品 | 内容 | 価格帯 |
| --- | --- | --- |
| ① 初めての方向け | 30分または45分の初回セッション | 30分：3,300〜5,500円／45分：5,500〜8,800円 |
| ② 通常セッション | 60分または90分 | 60分：11,000〜22,000円／90分：16,500〜33,000円 |
| ③ 継続セッション | 3回コース・月1回継続・講座 | システム対応が難しい場合は個人ページ内の案内文だけでも可 |

価格は一律にせず推奨価格帯のみ指定する（安売りサイトに見せない）。初回セッション終了時の高額商品の強引な販売は禁止。

## 6. 掲載条件・掲載フロー

**掲載条件**：ミラクルコレクション在籍／対象メソッド・認定資格を保有／顔写真とプロフィールを提出できる／予約可能枠を登録できる／利用規約・倫理基準に同意／予約への返信を24時間以内に行う／月に最低4枠以上を公開／セッション後の報告・口コミ依頼に対応する

会員全員を自動掲載せず、**活動意思のある人だけ**を掲載する。公開初月は情報が整った20〜30名から始める。

## 7. 運営体制（3ロール）

| 役割 | 担当内容 |
| --- | --- |
| スピなび事務局 | 掲載情報の確認、予約・決済トラブル対応、口コミ管理、予約枠未更新者への連絡 |
| 掲載メンバー | 予約枠の更新、顧客対応、セッション実施、感想取得、自分のSNSでの告知 |
| ダイナビジョン | LINE・メール・講座からの送客、毎月の特集テーマ決定、品質管理、数値確認、ミラコレ入会導線 |

---

## 8. 4週間スケジュール

| 週 | 内容 |
| --- | --- |
| 第1週 | 悩み6分類・セッション6分類・掲載条件・商品数上限（3）を確定／プロフィール統一フォーマット作成／利用規約・キャンセル規定確認／ミラコレ会員向け説明会 |
| 第2週 | ミラコレ会員へ掲載募集／掲載希望フォーム回収／顔写真・プロフィール・商品情報回収／得意な悩みカテゴリー登録／初期掲載20〜30名を確定 |
| 第3週 | 個人ページ作成／予約枠登録／決済接続／検索結果表示確認／予約確認メール確認／テスト予約・返金・日程変更テスト／スマホ表示確認 |
| 第4週 | 掲載者本人の最終確認／HIRO・穴口恵子さんの推薦メッセージ収録／LINE・メール配信準備／スピリア・公式サイトへバナー設置／告知テンプレート配布／先行公開→問題修正→正式公開 |

## 9. 集客先（既存媒体のみ／新規媒体は作らない）

| 媒体 | 掲載方法 | リンク先 |
| --- | --- | --- |
| ダイナビジョン公式サイト | 「認定専門家に相談する」常設ボタン | スピなびトップ |
| スピリア | 常設バナー・関連記事 | 悩み別ページ |
| ダイナビジョン公式LINE | リッチメニュー | 悩みカテゴリー |
| メールマガジン | 月1〜2回のテーマ配信 | テーマ別ページ |
| 各講座の会員ページ | 「学びを個別に実践する」 | 対応専門家 |
| YouTube | 概要欄・固定コメント | 動画テーマに合うページ |
| Instagram | プロフィールリンク | スピなびトップ |
| レインボーエンジェルズ | 店頭QR・商品同梱カード | 関連セッション |
| セミナー終了後 | 個別フォロー案内 | 講座別専門家 |

すべてをトップページへ送らず、発信内容と悩みカテゴリーを一致させる。

**公開時の集客企画は1つだけ**：「スピなびオープン記念企画」（HIRO・穴口恵子さんの公開メッセージ＋おすすめ専門家6名＋初めての方向けセッション特集＋期間限定予約枠、LINE・メールで3回程度案内、掲載者各自もSNSで紹介）。

## 10. 公開後に追う数字（7つに絞る）

- 掲載メンバー数
- 月間サイト訪問者数
- プロフィール閲覧数
- 予約件数
- セッション実施件数
- 30日以内の再予約率
- 予約が1件以上入った掲載者の割合

**最重要KPI**：「公開後90日以内に、掲載メンバーの何％に予約が入ったか」（初期目標50％）

**公開初月の仮目標**：掲載者20〜30名／予約可能枠100枠以上／新規予約30件／セッション実施25件以上／予約獲得者率30％以上／口コミ15件以上

## 12. 開発側に最優先で確認する9項目

1. 悩みとセッションの両方から検索できるか
2. 検索結果に料金と直近の空き日時が出るか
3. 日時選択から決済までスマートフォンで完結するか
4. ダブルブッキングを防止できるか
5. 予約変更・キャンセル・返金を処理できるか
6. 専門家ごとの予約数と売上を集計できるか
7. 予約者と専門家へ自動通知できるか
8. 専門家の公開・停止を事務局で管理できるか
9. **顧客・予約・決済・専門家データをCSV等で出力できるか**（将来システムを変更する場合の移行可否を左右する、最重要確認事項）

## まとめ

公開時の完成基準は機能の多さではない。

> 「利用者が3分以内に自分に合うセッションを見つけ、スマートフォンで予約・決済まで完了できること」

これがスピなび1か月公開版の最低完成ラインであり、本ドキュメントのサイトマップ・データモデル・4週間スケジュールが、その完成基準を満たすための最小構成である。
